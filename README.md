## 💡 编排与重构说明

- 原著受限于早年的翻译习惯，部分数学术语在今天看来略显生硬；同时原著带有浓厚的“翻译腔”色彩，十分不符合中文语境，直接阅读不太容易理解。因此，我对全书的一些专有名词和行文逻辑进行了一定程度的润色，拆分了冗长、从句繁多的复合句，调整了定语后置的定义句等，使其符合现代中文的阅读节奏，并尽量使其与当今高校通用的数学教材规范接轨。
- 根据个人习惯，我将书中出现的数学家人名统统还原为国际通用的外文原名（如 Cauchy, Lagrange 等）。
- 为了防止原版读者在转移到本版上感到不适应，我尽力做到原版的排版风格与引用习惯。这里借用了[李文威老师的《代数学方法》书籍模板](https://github.com/wenweili/AlJabr-1)并进行了更改，只是章节的排版与原版不同，但是内容顺序都是一致的。
- 作为 PDF，最大的好处就是能交叉引用。本 LaTeX 源码为书中的每一个子章节、定理、引理、例题等都打上了独立的 Label。所有针对前后文的引用均实现了精准的内部链接。读者在阅读 PDF 电子版时，只需点击链接即可快速跳转对应部分。

## 🛠️ 编译说明
如果你希望在本地克隆并自己编译本项目，推荐使用 XeLaTeX 引擎。进入对应卷的目录后先生成索引，再继续编译两遍，使目录、索引和交叉引用稳定：

```bash
cd 第一卷
xelatex main.tex
texindy main.idx
xelatex main.tex
xelatex main.tex
```

第二卷采用同一编译流程。当前第八至十二章仍是未经用户审核的初稿，源码分别处于单层外部 `comment` 环境中，正式的 `第二卷/main.tex` 暂不载入这些章节。
第二卷的目录与进度说明对应本地初稿，目前尚未作为发布源码上传；可下载的成稿为第一卷。

标题与证明环境默认使用 `Noto Sans CJK SC`。若本机尚未安装该字体，请先安装 Noto CJK 字体族，或在 `font-setup-open.tex` 中将相关字体替换为可用的 Fandol 黑体。

本次整理采用现代常用术语“数列”代替旧称“整序变量”，并保留原书的例题脉络和主要论证风格。原书正式小节的标签统一写作 `subsec:实际节号`，小节引用统一使用 `\emref{subsec:节号}`；若一个源码小节合并了原书多个正式小节，则使用它实际起始的原书节号，不按源码顺序重编。其他章节、定理、例题和公式继续采用语义化 label。正文中的手工编号使用项目自定义的 `\myrefparagraph` 命令，使 `1)`、`1°` 等编号既不造成列表缩进，又可以通过 `\label` 与 `\ref` 在后文引用；每个编号还具有独立的内部链接锚点，点击引用时能够准确落到对应正文位置。

第一卷当前在原版式基础上将正文区域向下延伸 `15mm`，并将页末标题的最小保留空间设为两个基线距离，以减少页面底部空间充足时仍提前换页的情况。
定理环境中的引理按章重新从 1 开始编号；几何示意图优先使用 TikZ 绘制，并可根据正文结构采用文字环绕排版。
